## 一、要先確認的決定

照「建議」規劃；有不同意見請在實作前提出。

## 二、現況重點

- `App.xaml` 的 `Application.Resources` 是空的，樣式都寫在 `MainWindow.xaml` 的 `Window.Resources`，所以快捷鍵一覽這類另外開的視窗、右鍵選單、滑鼠提示都套不到。`Button` 只改了底色，沒有改外觀範本，Windows 內建的範本在滑鼠移入時把底色改成 `#BEE6FD`（淺藍），停用時改成 `#F4F4F4`（淺灰）。
- `TimelineView` 拖曳時只處理滑鼠在視窗內的移動，沒有自動捲動；`KeepPlayheadVisible` 只在播放時讓播放頭留在畫面內。
- `Timeline.Remove` 只拿掉片段，後面的片段不動。
- `MediaItem` 沒有 `INotifyPropertyChanged`（健檢報告 W-7），素材清單的內容建立後不會更新。
- `FfmpegLocator.Locate` 依序找程式目錄下的 `tools\ffmpeg`、程式目錄、PATH；找不到時 `MainWindow` 的建構式顯示 `FatalPanel` 後就結束，之後的元件都沒有建立。
- 時間軸每個播放 tick 都整個重畫（健檢報告 W-2，尚未量測）。縮圖會讓每次重畫多畫圖片，要注意成本。
- `FrameExtractor.ThumbnailAsync`、`LruCache` 已經有，可以拿來產生與快取縮圖。

## 三、階段

### 階段 1：深色樣式（#1、#8）

- 樣式從 `MainWindow.xaml` 搬到 `App.xaml`（`Application.Resources`），另外開的視窗、右鍵選單、滑鼠提示也都套得到。顏色都用 `Palette`。
- **按鈕**：自己寫 `ControlTemplate`（圓角邊框加上內容）。一般 `#3A3A3A`；滑鼠移入 `#474747`；按下 `#2E2E2E`；停用時底色 `#2C2C2C`、文字 `TextDim`。焦點外框沿用第一輪的強調色外框。
- **右鍵選單**：`ContextMenu`、`MenuItem`、`Separator` 改成深色底、淺色字，滑鼠移入時加亮，停用的項目變暗，勾選項目顯示 ✓。
- **滑鼠提示**：`ToolTip` 改成深色底、細邊框，最大寬度 400，文字自動換行。
- **勾選框、輸入框**：`CheckBox` 的方框改成深色；`TextBox` 統一深色底、取得焦點時邊框變成強調色（目前音量與輸入時間的輸入框各自寫了顏色，改用同一個樣式）。
- **捲軸**（可選）：預設的亮色捲軸改成細的深色捲軸。範本比較長，如果階段 1 太大就移到之後。
- 不處理：`MessageBox` 和檔案對話方塊是 Windows 原生視窗，WPF 的樣式改不到，維持原樣。

### 階段 2：狀態列淡出、選擇 FFmpeg 位置（#9、#10）

**狀態列淡出（#9）**
- Core 新增 `StatusPolicy.Lifetime(kind, hasAction)`：照決定 9 回傳訊息要留多久，或永久保留。
- App：`ShowStatus` 依照回傳值啟動計時器，時間到時用 0.3 秒淡出後清空；新訊息會取消舊的計時器；滑鼠停在狀態列上時暫停計時。
- 測試：每一種訊息的保留時間。

**找不到 FFmpeg（#10）**
- `FatalPanel` 改成一張說明卡片，包含：
  - 找不到什麼，以及程式找過哪些位置（程式目錄的 `tools\ffmpeg`、程式目錄、PATH）。
  - 「選擇 FFmpeg 所在資料夾…」按鈕（`OpenFolderDialog`）。
  - 「下載說明」連結，用預設瀏覽器開啟 FFmpeg 官方下載頁（ffmpeg.org/download.html）。
- 選好資料夾後檢查裡面有 `ffmpeg.exe` 與 `ffprobe.exe`；有的話存到設定檔（`AppSettings.FfmpegFolder`），並自動重新啟動程式；沒有的話在卡片上說明。
- `FfmpegLocator.Locate` 加上 `preferredDirectory` 參數，最先找這個位置（決定 8）。這個位置不能是相對路徑（沿用 PATH 的安全規則）；資料夾已經不在，或裡面找不到程式時，就照原本的順序找。
- 狀態列右側的 FFmpeg 版本可以點，點了也能重新選資料夾（滑鼠提示說明）。
- 測試：偏好的位置排第一、偏好的位置不存在或是相對路徑時改照原本的順序、設定檔的新欄位。

### 階段 3：剪輯操作（#3、#4、#5、#12）

**自動捲動（#3）**
- `TimelineView`：拖曳片段、修剪、拖曳播放頭、拖入素材時，游標在時間軸左右邊緣 40 像素以內就開始自動捲動，越靠近邊緣越快，最快每秒捲動一個畫面寬。用 `DispatcherTimer`（每 30 毫秒）捲動，並用最後的游標位置重新套用拖曳，所以片段會跟著移動；放開滑鼠或游標離開邊緣時停止。
- Core 新增 `TimelineDrag.AutoScrollSpeed(x, left, right)`：計算捲動速度。測試：中間不捲、越靠近邊緣越快、超出邊緣時用最快速度。

**刪除並補齊（#4）**
- Core 新增 `Timeline.RemoveAndClose(clip)`：照決定 6 刪除片段，同一軌後面的片段往前移，回傳移動的距離。
- App：Shift+Delete、右鍵選單「刪除並補齊」，記成一步復原；狀態列說明「後面 N 段往前移 X 秒」。
- 測試：後面的片段往前移、片段之間的空白不變、刪除 V1 時 A2 不動、刪除最後一段時其他片段都不動、可以復原。

**快捷鍵（#5、#12）**
- 照決定 7 加上快捷鍵；`PreviewKey`、`PreviewCommand`、`Shortcuts`（F1 一覽）一起更新。
- Home／End：跳到開頭與結尾。剪輯預覽時移動播放頭；匯入影片預覽時移動素材的位置。
- `+`／`-`：和工具列的 ＋／－ 按鈕相同。
- E：等同「＋ 加入時間軸」。
- **插入到播放頭（#12）**：Shift+E，播放列也加一個「插入到播放頭」按鈕。把目前預覽的素材（含入出點）用拖曳插入的規則放到時間軸播放頭的位置：播放頭在片段的前半就插在它前面，後半就插在它後面。使用 `TimelineEditor.AddAt`。
- Alt+←／→：選取前一段／後一段片段，並把播放頭移到那段的開頭。Core 新增 `TimelineNavigation.Adjacent(clips, selected, direction)`。沒有選取時，選播放頭所在的那段，沒有的話選最近的那段。
- Alt 按下時 WPF 傳來的是 `Key.System`，要改看 `e.SystemKey`。拖曳時按住 Alt 暫停吸附的功能不受影響（那是拖曳中持續按著，不是按一下）。
- 測試：`Adjacent` 的頭尾與沒有選取時的情況；新快捷鍵都有列在 F1 一覽裡（沿用既有的測試）。

### 階段 4：片段提示與素材使用標記（#7、#11）

**片段的滑鼠提示（#7）**
- Core 新增 `ClipDescription.Describe(clip, fps, display)`，回傳幾行文字：
  - 檔名、在時間軸上的開始與結束、長度
  - 來源的入點與出點
  - 音量、倒放、旋轉鏡像、畫面位置（只列有改過的）
- `TimelineView`：滑鼠移到另一段片段上時更新 `ToolTip` 的內容；拖曳中不顯示。時間格式跟隨目前的顯示方式。
- 測試：一般影片、配樂、圖片、倒放加旋轉的片段各自的文字。

**素材使用標記（#11）**
- `MediaItem` 實作 `INotifyPropertyChanged`，新增 `UsageCount`（在時間軸上用了幾段）。每次 `OnClipsChanged` 時重新計算。這也處理了健檢報告 W-7 的一部分。
- 素材清單的項目在縮圖角落加小標記「2 段」；沒用到的素材不顯示。滑鼠提示說明「時間軸上有 2 段使用這個素材」。

### 階段 5：時間軸縮圖（#6）

- Core 新增 `ThumbnailPlan.Times(clip, pixelsPerSecond, thumbWidth, visibleRange)`：照決定 10，回傳這段片段在畫面上要畫哪幾張縮圖（畫的位置，以及對應的來源時間）。倒放的片段從來源的結尾往回取；只計算看得到的範圍；來源時間對齊到影格，讓快取比較容易命中。
- App 新增 `TimelineThumbnails`：
  - 用 `FrameExtractor.ThumbnailAsync` 在背景產生縮圖，一次只跑一個 FFmpeg，以（路徑, 影格）當快取鍵存在 `LruCache`（最多 300 張）。
  - 縮圖產生好之後，時間軸只重畫一次（合併 100 毫秒內完成的縮圖），避免一直重畫。
  - 捲動或縮放時，取消已經看不到的縮圖請求。
  - 圖片片段直接用匯入時產生的縮圖。
- 繪製時套用片段的旋轉與鏡像。縮圖畫在片段底色上，檔名等文字放在半透明深色底上。片段太窄（小於 24 像素）時不畫縮圖。
- 播放時的重畫成本（W-2）：縮圖用凍結的 `BitmapSource`，畫圖本身很便宜；如果在 Windows 上量測後仍然太慢，再照 W-2 的建議把播放頭拆成獨立的圖層。
- 測試：`ThumbnailPlan` 在各種縮放比例下的張數與位置、倒放、只計算看得到的範圍、太窄不畫、對齊到影格。

### 階段 6：專案存檔與自動恢復（#2）

**Core（`Project/` 資料夾）**
- `ProjectFile`：照決定 2 的 JSON 格式，包含版本號、素材清單（絕對路徑、相對路徑）、兩軌的片段（素材索引、來源入點出點、位置、音量、倒放、旋轉鏡像、畫面位置）、畫面比例與處理方式。
- `ProjectSerializer.Save(timeline, media, settings, path)`／`Load(path)`：讀取時檢查版本號與內容是否合理（例如索引超出範圍、時間是負的），不合理就回傳錯誤，不讓程式當掉。
- `ProjectLoader`：開啟流程。
  - 依序用絕對路徑、相對路徑找每個素材；找到後用 `MediaProbe` 重新讀取素材資訊。
  - 找不到的素材交給畫面處理（決定 3）。
  - 依照讀回的素材建立時間軸。片段超出素材長度（例如素材被換成比較短的檔案）時，略過那段並說明。
- `ProjectState`：判斷有沒有沒存的變更。比較存檔時的時間軸快照（第一輪的 `TimelineSnapshot`）與輸出設定，和現在的是否相同。
- `AutoSave`：照決定 4 的時機寫入與刪除自動存檔，並判斷開啟時是否要詢問還原。計時用 `TimeProvider` 注入，方便測試。

**App**
- 視窗上方新增一排檔案按鈕：「新專案」「開啟…」「儲存」「另存新檔…」，加上決定 7 的快捷鍵。視窗標題顯示專案名稱，有沒存的變更時加上 `*`。
- 關閉、開新專案、開啟另一個專案之前，照決定 5 詢問是否儲存。
- 開啟時有素材找不到：用一個對話框列出這些檔案，每列有「重新指定…」與「略過」。
- 程式啟動時發現上次的自動存檔，詢問「上次的剪輯沒有存檔就關閉了，要還原嗎？」
- 開啟專案時，素材清單、時間軸、畫面比例與處理方式都換成專案的內容，並清空復原紀錄。

**規格**
- 第 4 節非目標拿掉「專案存檔」；第 3 節新增一小節說明專案檔的內容、找不到素材時的處理、自動恢復。

**測試**
- 存檔後讀回內容相同（所有片段屬性、兩軌、輸出設定）。
- 整個資料夾搬家後用相對路徑找得到素材；找不到的素材回報給畫面。
- 版本號不對、內容壞掉時回傳錯誤，不丟出例外。
- 片段超出素材長度時略過並說明。
- 有沒有沒存的變更：修改後是、復原回存檔時的樣子後不是、改輸出設定後是。
- 自動存檔：只在修改後 3 秒存，沒有修改不存；正常關閉時刪除；開啟時是否詢問還原。
- 開啟專案的整合測試，用 FFmpeg 產生的測試影片。

## 四、需要在 Windows 上手動驗證

- 按鈕、右鍵選單、滑鼠提示、勾選框、輸入框在滑鼠移入、按下、停用、取得焦點時的樣子；高 DPI（150%）下也要看。
- 找不到 FFmpeg 時的卡片：選錯資料夾、選對資料夾後自動重新啟動、點狀態列的 FFmpeg 版本重新選。
- 拖曳片段、修剪、拖曳播放頭、拖入素材到邊緣時自動捲動，速度是否適中。
- 新快捷鍵；Alt+←／→ 不會觸發其他功能；E 與 Shift+E 在焦點在不同地方時的行為。
- 縮圖：大量片段時捲動與播放是否流暢、旋轉鏡像後的縮圖方向、倒放片段。
- 專案：存檔、開啟、搬資料夾後開啟、素材被刪除後開啟、在工作管理員結束程式後重新開啟會詢問還原。
