# 個人影片編輯器

依 [video-editor-spec.md](video-editor-spec.md) 實作的 Windows 影片編輯工具（C# / WPF）。

## 執行

需要 .NET 10 SDK，以及 `ffmpeg.exe` 與 `ffprobe.exe`（放在程式目錄的 `tools\ffmpeg`，或加入 PATH）。FFmpeg 必須含 libx264 與 libx265。

```bash
dotnet run --project src/VideoEditor.App
```

第一次啟動時 LibVLC 要掃描外掛，視窗可能過一段時間才出現。

```bash
dotnet test
```

## 打包

在 Windows PowerShell 執行，會把程式與 ffmpeg 一起放進 `dist\VideoEditor`（自包含，對方不必安裝 .NET）：

```powershell
.\scripts\pack.ps1                              # ffmpeg 從 PATH 尋找
.\scripts\pack.ps1 -FfmpegDir C:\ffmpeg\bin -Zip  # 指定 ffmpeg 位置，並另外壓成 dist\VideoEditor.zip
```

其他參數：`-Output` 輸出資料夾、`-FrameworkDependent` 不內含 .NET 執行階段、`-SkipFfmpeg` 不複製 ffmpeg。

## 操作

| 按鍵 | 功能 |
|---|---|
| 空白鍵 | 播放／暫停 |
| J | 倒帶（往回播放）；倒帶中再按加速為 2×、4×、8× |
| L | 播放；播放中再按快轉為 2×、4×、8× |
| K | 暫停 |
| ← / → | 前一格／後一格 |
| I / O | 設定入點／出點（素材模式） |
| Delete | 刪除選取的片段 |
| Ctrl + 滾輪 | 縮放時間軸 |

## 與規格不同的決定

| 項目 | 規格 | 實作 | 原因 |
|---|---|---|---|
| .NET 版本 | .NET 8 | .NET 10 | .NET 8 於 2026-11-10 結束支援 |
| 切點參數 | `-ss` / `-to` 放在輸入之後 | `-ss` / `-t` 放在 `-i` 之前 | 重新編碼時同樣準確，而且不必從頭解碼 |
| 匯出進度 | 讀標準錯誤 | 讀 `-progress pipe:1` | 標準錯誤只用於錯誤訊息 |
| 編碼格式 | H.264 | 8-bit 用 H.264；10-bit 以上或 HDR 用 H.265 | H.264 一般是 8-bit，無法保留來源位元深度 |
| 音訊位元率 | 不低於來源 | 來源值，下限 192k、上限 512k | PCM 等高位元率來源超出 AAC 實務上限 |
| 畫質驗收 | 與來源無明顯差異 | 只比對未放大的情況 | 填滿裁切依解析度規則常需放大（1080p 來源為 1.78 倍） |

## 進度顯示

匯入素材、產生倒放預覽、匯出時，預覽畫面下方會出現進度面板（不會推動其他版面），工作結束後自動收起：

| 項目 | 顯示內容 |
|---|---|
| 讀取素材 | 第幾個／共幾個、檔名、目前步驟（讀取資訊／產生縮圖）、百分比 |
| 準備倒放預覽 | 百分比 |
| 匯出 | 檔名與解析度、百分比、預估剩餘時間、取消按鈕；完成後顯示「匯出完成」與花費時間約 4 秒。Windows 工作列圖示也會顯示匯出進度 |

## 規格未定義、由實作決定的行為

- **基準素材**：輸出解析度、影格率與色彩都以時間軸上第一個影片片段為準。片段不一致時，匯出前會提示。
- **原尺寸**：規格之外新增的比例選項，也是預設值。輸出沿用基準素材的長寬（奇數會調成偶數）；其他尺寸不同的片段依「處理方式」裁切或加黑邊。
- **軌道**：V1 放影片，A1 放影片原音並與 V1 連動（不可分離），A2 放配樂。
- **編輯規則**：同軌片段不可重疊，可留空白；拖曳不會推動其他片段。空白處輸出黑畫面與靜音。
- **配樂比影片長**：以黑畫面補到時間軸結束。
- **音量**：每段 0–200%，為線性增益；多聲道音訊混音為立體聲。
- **片段倒放**：選取影片軌片段後勾選「倒放這個片段」，畫面與原音一起倒放，位置與長度不變。配樂（A2）不能倒放。倒放片段的左緣是來源的出點、右緣是入點，修剪時依此調整。
- **倒放的匯出**：FFmpeg 的 `reverse` 濾鏡要把整段影格放在記憶體裡，所以每個倒放片段會切成多小段（每段解碼後約 512 MB 以內）各自倒放，再由後往前接起來。
- **倒放的預覽**：LibVLC 不能倒著播放，所以第一次播放到倒放片段時，會先在背景產生一個縮小的倒放預覽檔（勾選倒放時就開始產生），產生完才繼續播放。預覽檔放在暫存資料夾，關閉程式時刪除。
- **旋轉與鏡像**：選取影片軌片段後，可左轉／右轉 90°、水平或垂直鏡像，預覽與匯出一致。順序固定為先旋轉、再鏡像；鏡像後再旋轉時，依畫面上看到的方向轉。像素比會在旋轉前修正。旋轉 90°／270° 的片段若是時間軸上第一個片段，「原尺寸」輸出會跟著變成直式；與其他片段方向不同時，匯出前會提示解析度不一致。旋轉以 `transpose` 搬移像素，不影響畫質。配樂（A2）沒有畫面，不適用。
- **快轉（L 或「▶▶ 快轉」）**：只用於預覽，不影響匯出。由 LibVLC 以倍速播放，按鈕在停止時直接從 2× 開始。2× 仍有聲音，4× 以上靜音。暫停、倒帶、拖曳播放頭都會回到正常速度。
- **倒帶（J）**：只用於預覽，不影響匯出。由 FFmpeg 一次解出多格來顯示，沒有聲音；高倍速時每隔幾格才取一格。

## 已知限制

- 很長的高解析度倒放片段（例如數分鐘的 4K 10-bit）會切成很多小段，可能超過 Windows 命令列長度上限而無法匯出，需要把片段剪短。
- 倒帶播放的流暢度取決於 FFmpeg 解碼速度，長 GOP 的素材可能會跳格。

- 預覽切換片段時約有 0.1–0.3 秒停頓（LibVLC 載入時間），匯出不受影響。
- HDR 素材的預覽沒有做色調對應，顏色會偏淡；匯出會保留 HDR 標記。
- HDR 靜態中繼資料（mastering display）沒有明確保留。
- 不同色彩格式的片段接合時只統一格式，不做色調對應。
